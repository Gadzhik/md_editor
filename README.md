# Markdown Editor V4 (AI Powered)

Современный, быстрый и функциональный редактор Markdown, созданный на базе Electron. Позволяет работать с локальными файлами, проектами и использовать возможности искусственного интеллекта для написания и редактирования текстов.

## Основные возможности

-   **Полноценный Markdown**: поддержка GFM, таблиц, списков задач.
-   **Математика и Диаграммы**: рендеринг формул через **KaTeX** и диаграмм через **Mermaid**.
-   **Управление проектами**: древовидный проводник (Explorer) для работы с папками.
-   **Система вкладок**: работайте с несколькими файлами одновременно.
-   **Запоминание позиции чтения**: для каждого файла отдельно сохраняется и восстанавливается место прокрутки — между переключениями вкладок и перезапусками приложения. Работает даже при скрытой панели редактора (позиция берётся из окна предпросмотра).
-   **Автосохранение с ограничением бэкапов**: резервная копия (`*.backup-…`) создаётся только при реальном изменении файла, и для каждого файла хранится не более N последних копий (по умолчанию 3 — параметр `autoSaveBackupLimit`), чтобы не засорять диск.
-   **Интеграция с AI (V4)**:
    -   **AI Chat**: боковая панель для обсуждения текста.
    -   **Inline Assistant**: выделяйте текст и запрашивайте улучшения (Rewrite, Explain, Summarize) прямо в редакторе.
    -   Поддержка локальных LLM через **Ollama** или **LM Studio** (OpenAI-совместимый API).
-   **Git Auto-versioning**: автоматические коммиты при сохранении (если папка является Git-репозиторием).
-   **Экспорт**: сохранение заметок в форматы **PDF** и **HTML**.
-   **Zen Mode**: режим фокусировки (F11) для работы без отвлекающих факторов.
-   **Кастомизация UI**: возможность скрывать боковую панель, редактор или окно предпросмотра для настройки идеального рабочего пространства.
-   **Гибкие настройки**: быстрая смена провайдера и автоматическое переключение адреса сервера (порт 11434 для Ollama, 1234 для LM Studio).

## Установка и запуск

### Предварительные требования
1.  Установленный [Node.js](https://nodejs.org/) (рекомендуется LTS версия).
2.  (Опционально) Установленный [Ollama](https://ollama.com/) или [LM Studio](https://lmstudio.ai/) для работы локального AI.

### Шаги установки
1.  Склонируйте или скачайте репозиторий.
2.  Откройте терминал в папке проекта.
3.  Установите зависимости:
    ```bash
    npm install
    ```
4.  Запустите приложение:
    ```bash
    npm start
    ```

> **Запуск под Linux:** если зависимости ставились под Windows, в `node_modules` лежит Windows-сборка Electron и `npm start` падает с `Syntax error: end of file unexpected`. Варианты:
>
> - переустановить Electron под Linux: `npm install electron@29.4.6` (это сломает сборку под Windows, если она нужна);
> - либо запустить исходник распакованным Linux-Electron из кэша:
>
>   ```bash
>   unzip -q ~/.cache/electron/electron-v29.4.6-linux-x64.zip -d /tmp/electron-linux
>   ELECTRON_ENABLE_LOGGING=1 /tmp/electron-linux/electron . --no-sandbox --enable-logging
>   ```

## Сборка и установка

### Распакованная сборка (для тестирования)

Быстрая сборка без создания установщика. Результат — готовая к запуску папка с `.exe` файлом.

```bash
npm run pack
```

Результат: `dist/win-unpacked/Markdown Editor V3.exe` — можно запускать напрямую, копировать на флешку или другой ПК.

### Установщик Windows (NSIS)

Полноценный инсталлятор для распространения. Создаёт `.exe`-установщик с автоматической установкой, ярлыками и деинсталлятором.

```bash
npm run dist
```

Результат: `dist/Markdown Editor V3 Setup 3.0.0.exe`

### Сборка для Linux (.AppImage, .deb)

```bash
npm run dist:linux
```

Результат в папке `dist/`:

-   `linux-unpacked/md-editor` — распакованный бинарь, запуск: `./dist/linux-unpacked/md-editor --no-sandbox`
-   `Markdown Editor V3-3.0.0.AppImage` — портативный запуск (`chmod +x`, затем запустить)
-   `md-editor_3.0.0_amd64.deb` — установка: `sudo dpkg -i dist/md-editor_3.0.0_amd64.deb`

> electron-builder сам скачивает нужный Linux-Electron в кэш (`~/.cache/electron`), поэтому Windows-сборка в `node_modules` сборке под Linux не мешает.

### Сборка для других платформ

По умолчанию `electron-builder` собирает под текущую ОС. Для кросс-платформенной сборки:

```bash
# macOS (.dmg)
npx electron-builder --mac

# Linux (.AppImage, .deb)
npx electron-builder --linux
```

> **Примечание:** кросс-компиляция (например, сборка macOS-версии на Windows) имеет ограничения. Для надёжного результата рекомендуется собирать на целевой ОС.

### Параметры сборки

Конфигурация находится в `package.json` → секция `build`:

| Параметр | Значение |
|----------|----------|
| `appId` | `com.mdeditor.local` |
| `productName` | `Markdown Editor V3` |
| `directories.output` | `dist` |
| `win.target` | `nsis` |

## Горячие клавиши

-   `Ctrl + O`: Открыть файл.
-   `Ctrl + Shift + O`: Открыть папку проекта.
-   `Ctrl + S`: Сохранить текущий файл.
-   `Ctrl + F`: Поиск по тексту.
-   `Ctrl + B`: Сделать выделенный текст жирным.
-   `Ctrl + I`: Сделать выделенный текст курсивом.
-   `F11`: Переключить Zen Mode (режим фокусировки).
-   `Ctrl + E`: Показать/скрыть Редактор.
-   `Ctrl + Shift + B`: Показать/скрыть Боковую панель (Sidebar).
-   `Ctrl + Shift + P`: Показать/скрыть Окно предпросмотра (Preview).
-   `Esc`: Закрыть модальные окна (настройки AI).

## Настройка AI

Редактор поддерживает два основных способа подключения локального AI:

### Вариант А: Ollama (по умолчанию)
1.  Убедитесь, что **Ollama** запущена.
2.  В приложении откройте настройки AI (⚙️).
3.  Выберите провайдера **Ollama**. Адрес сервера автоматически установится на `http://localhost:11434`.

### Вариант Б: LM Studio
1.  Запустите **LM Studio** и включите Local Server.
2.  В приложении откройте настройки AI (⚙️).
3.  Выберите провайдера **LM Studio / Compatible**. Адрес сервера автоматически изменится на `http://localhost:1234`.

### Общие шаги
1.  После выбора провайдера нажмите **Test Connection & Fetch Models**.
2.  Выберите нужную модель из появившегося списка.
3.  Нажмите **Save & Close**.
